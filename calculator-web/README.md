# calculator-web

calculator-web 是一個計算機小程式專案。

## 功能特性

- 支援基本的四則運算 (+, -, *, /)
- 支援百分比計算 (%)
- 支援括號運算 ()
- 鍵盤操作支援 (數字鍵、Enter、Backspace、Escape)
- 響應式設計，支援各種螢幕尺寸

## 安裝方式

```bash
# 安裝依賴
pip install -r requirements.txt

# 啟動服務
python app.py
```

## 使用方式

1. 輸入要計算的表達式
2. 點擊計算按鈕或按 Enter 鍵
3. 查看計算結果
